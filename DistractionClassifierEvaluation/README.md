# Windows Native Classifier Diagnostics

The Windows classifier runs locally in C# with ONNX Runtime, in shadow mode.

Set FOCUSBEAR_DISAGREEMENT_EVAL=1 to run five predefined native examples after login. This optional diagnostic does not call the backend or change blocking decisions.

Prediction logs are written to:
%LOCALAPPDATA%\FocusBear\native-relevance-shadow.log

The two windows_all CSV files contain historical 900-example evaluation results. They were generated by the earlier evaluator and do not validate the current native integration.

Live backend disagreement logging is implemented separately in Focus/GentleBlock.xaml.cs. YouTube watch predictions are deferred to the browser's stable-title queue.
